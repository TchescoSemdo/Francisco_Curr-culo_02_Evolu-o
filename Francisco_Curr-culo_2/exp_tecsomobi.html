Redução Crítica de Falhas Operacionais
  • Reduzi falhas em campo de 8% para 0,5% liderando QA técnica no lançamento e expansão de aplicativos para novas praças/cidades (expansão geográfica)
  • Estratégia de testes cobrindo 15+ cenários críticos do fluxo completo:

    • Timeout em cada etapa (5s, 10s, 30s, 60s)
    • Falha de rede durante pagamento (retry exponencial)

  • Garantia de estabilidade operacional no go-live em múltiplas cidades, evitando impacto em usuários finais e reduzindo chamados de suporte em 60%
Conformidade PIX em Larga Escala
  • Validei conformidade de 50K+ pagamentos PIX mensais garantindo:
    • Idempotência: Prevenção de pagamentos duplicados mesmo com retry do usuário (validação de chave de idempotência única por transação)
    • Ausência de duplicidade: Validação de transações únicas por chave transacional, impedindo cobranças múltiplas pelo mesmo serviço
    • Tratamento de timeout: Cenários de 5s, 10s, 30s, 60s com retry exponencial (backoff: 2s, 4s, 8s) e circuit breaker após 3 falhas consecutivas
    • Conciliação financeira: Zero inconsistências transacionais detectadas através de queries SQL validando cadeia completa (intenção → pagamento → ordem → token → arquivo incremental)
    • Validação de estados: Máquina de estados completa (pendente → processando → pago → expirado → cancelado → reembolsado)
  • Integração com PSP (Payment Service Provider) e compliance com regulamentações do Banco Central (SPI - Sistema de Pagamentos Instantâneos)
  • Monitoramento proativo com alertas configurados no CloudWatch para taxas de erro > 1%, latência > 10s, disponibilidade < 99%
Framework de Automação API - Eliminação de Dependências
  • Desenvolvi framework de automação API no Postman eliminando 6+ dependências manuais que atrasavam execução de testes:
    1. Sites geradores de CPF → Algoritmo validador de CPF implementado (cálculo dos dígitos verificadores)
    2. Sites geradores de email → Geração dinâmica padronizada (padrão: qa_test_{timestamp}@mailsac.com)
    3. Provedores de email temporário → Integração com Mailsac API para criação automática de caixas de entrada descartáveis
    4. Criação manual de massa de teste → Scripts automatizados de cleanup (DELETE em cascata após execução)
    5. Validação manual de recebimento de email → Polling automático de inbox (intervalo de 2s, timeout 60s)
    6. Extração manual de códigos de confirmação → Regex para extração de OTP (/\d{6}/ para código de 6 dígitos)
  • Resultado quantificado: Redução de setup de massa de testes de 2-4 minutos para 8 segundos (melhoria de 1500%-3000%)
  • Beneficiara 12+ pessoas (QAs, Devs, Suprote e ETC)

Ferramenta Smart_Locator - Redução de Manutenção
  • Criei ferramenta interna para automação mobile que reduziu manutenção de locators em 70%
  • Funcionalidades implementadas:
    • Geração automática de XPath otimizados (evita caminhos absolutos frágeis)
    • Fallback strategies em cascata:
